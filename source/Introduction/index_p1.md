# Unit 02 — Python Programming Fundamentals

Welcome to the first programming unit of the course. In this unit, we will learn
how to express instructions with [Python](https://www.python.org/), execute them
in different environments and use evidence to decide whether a program behaves
as intended.

Python is widely used in engineering, management, data analysis, automation and
artificial intelligence. It is also an excellent first programming language:
its syntax lets us concentrate on the ideas behind a program without hiding the
need for precision, testing and clear reasoning.

During the unit, we will use two complementary environments:

- **Google Colab** for guided notebooks, short experiments and classroom work;
- **Visual Studio Code** with local Python and Jupyter for projects, files, Git
  and governed AI assistance.

We will also use **Git and GitHub** to preserve the history of our work. Gemini
and Cline may support learning during class, but their suggestions must follow
the assistance level defined for each activity and must always be understood,
tested and explained by the student.

## Unit learning objectives

By the end of the unit, you should be able to:

- distinguish source code, a programming environment and an execution
  environment;
- write and execute Python instructions in notebooks and scripts;
- call built-in and library functions and import Python modules;
- represent program state with variables and basic data types;
- construct numeric expressions and convert values deliberately;
- express decisions with Boolean expressions and conditional structures;
- repeat operations with `for`, `range()` and lists;
- construct and represent a simple numeric series;
- use Git to record and publish meaningful versions of your work;
- use AI assistance responsibly and verify every adopted suggestion.

The recurring learning cycle is:

> **predict → execute → compare → explain**

## Session 08 — Loops, lists, series and visualisation

**Date:** 6 October

**Focus:** Repeat operations, preserve successive results and represent an
ordered series graphically.

We will introduce iterables, `for`, `range()`, lists, integer indexing,
`append()` and accumulators. We will construct a simple numeric series, locate
positions that require attention and create an introductory Matplotlib plot.
